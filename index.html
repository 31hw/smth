    How it works

    1. Shuffles Roblox catalog searches (keywords, categories, price caps) for fresh candidates.
    2. Pulls Rolimons' item list as a second pool.
    3. Verifies each candidate's real creation date, price and limited flags.
    4. Returns the first one that is buyable, non-limited and old enough — or says so.

    Rolimons itself doesn't expose a public API, so this uses its public item feed plus Roblox's catalog API. Nothing is filtered with fake fallbacks: if the item isn't genuinely eligible, it doesn't get shown.
